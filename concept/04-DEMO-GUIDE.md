## 🎬 Recording Tips

### Equipment Needed
- Screen recording software (OBS, QuickTime, ScreenFlow)
- Good microphone (clear audio is crucial)
- Script printed out
- Demo environment prepared

### Before Recording
1. ✅ Close unnecessary apps
2. ✅ Clean desktop/browser
3. ✅ Prepare demo data in NEXUS
4. ✅ Test all features work
5. ✅ Rehearse script 3x
6. ✅ Set up screen resolution (1920x1080)
7. ✅ Disable notifications

### During Recording
- **Speak clearly and enthusiastically**
- **Show, don't just tell** - demonstrate features live
- **Keep pace brisk** - 3 minutes goes fast
- **Record multiple takes** - choose the best one
- **Have backup recording** - in case first attempt fails

### After Recording
- **Edit for pacing** - cut dead time
- **Add text overlays** - emphasize key points
- **Color grade** - make it look professional
- **Add background music** (optional, subtle)
- **Export at 1080p 60fps**
