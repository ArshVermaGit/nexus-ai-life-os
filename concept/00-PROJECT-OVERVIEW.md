## 💡 Core Features

### 1. Continuous Awareness
- Captures screen every 2 seconds
- Records audio from meetings, calls, videos
- Tracks application usage and context
- Monitors file operations and changes

### 2. Intelligent Memory
- Stores everything in searchable format
- Semantic search: find anything by meaning, not just keywords
- Timeline view: see exactly what you were doing at any time
- Context preservation: captures full context of every moment

### 3. Proactive Intelligence
NEXUS watches for:
- **Mistakes about to happen**
  - Sending email to wrong person
  - Forgetting attachments
  - About to delete important files
  - Pasting passwords in public places

- **Missed opportunities**
  - Forgotten commitments
  - Approaching deadlines
  - Related work you've done before
  - People you promised to follow up with

- **Productivity blockers**
  - Too many context switches
  - Working during your low-energy times
  - Repeating work you've already done

### 4. Natural Language Interface
Ask NEXUS anything:
- "What was I working on last Tuesday at 3pm?"
- "Show me all insights about quantum computing from the past month"
- "What did Sarah say about the marketing budget?"
- "Find that article I read about AI safety"

### 5. Knowledge Synthesis
NEXUS connects ideas across:
- Articles you've read
- Videos you've watched
- Meetings you've attended
- Documents you've created
- Conversations you've had

Then generates insights you wouldn't have seen yourself.

## 🔒 Privacy & Security

### Core Principles
1. **Local First**: All data stored on your device
2. **Encrypted**: End-to-end encryption for all memories
3. **Transparent**: You control what NEXUS watches
4. **Deletable**: Easy one-click delete of any memory or all data
5. **No Cloud**: Nothing leaves your computer without permission

### Privacy Controls
- Pause recording anytime
- Exclude specific apps/websites
- Auto-pause during private browsing
- Redact sensitive information (passwords, credit cards)
- Export/delete all data

## 🛠 Technical Stack

### Core Technologies
- **Python**: Main application logic
- **Gemini 3 Live API**: Real-time multimodal analysis
- **Gemini 3 Standard API**: Batch processing and reasoning
- **ChromaDB**: Vector database for semantic search
- **SQLite**: Structured data storage
- **Electron** (optional): Cross-platform desktop app

### Key Libraries
- `mss`: Screen capture
- `pyaudio`: Audio recording
- `opencv-python`: Image processing
- `anthropic`: Gemini API client
- `chromadb`: Vector embeddings
- `pytesseract`: OCR for text extraction
